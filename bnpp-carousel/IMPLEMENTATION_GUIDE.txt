/* ============================================
   1. INSTALLATION
   ============================================

   A) Copy the entire bnpp-carousel-homepaGZ folder to wp-content/plugins/
   B) Log in to WordPress admin dashboard
   C) Navigate to Plugins > Installed Plugins
   D) Find "BNPP Carousel HomepagGZ" and click "Activate"
   E) The block will now appear in the block editor

   Activation Requirements:
   - WordPress 6.0 or higher
   - PHP 7.4 or higher
   - Active theme must support Gutenberg blocks

*/

/* ============================================
   3. BLOCK REGISTRATION FLOW
   ============================================

   FLOW DIAGRAM:
   
   WordPress Initialization
        ↓
   block.php loaded
        ↓
   Defines plugin constants
        ↓
   Includes src/init.php
        ↓
   Hook: 'init' fires
        ↓
   bnpp_carousel_register_block() executes
        ↓
   wp_register_script() ← assets/block.js
   wp_register_style()  ← assets/block.css
   register_block_type('bnpp/carousel-homepage')
        ↓
   Block available in editor
   
   FRONTEND RENDERING:
   
   User adds block to page
        ↓
   Attributes saved to post_meta
        ↓
   Page rendered
        ↓
   Hook: 'wp_enqueue_scripts'
        ↓
   Frontend JS/CSS loaded
        ↓
   bnpp_carousel_render_block($attributes) called
        ↓
   PHP generates HTML
        ↓
   JavaScript initializes carousel
        ↓
   User sees interactive carousel

*/

/* ============================================
   4. ATTRIBUTES & DATA STRUCTURE
   ============================================

   Block attributes are stored in post_meta as JSON:

   {
     "slides": [
       {
         "id": 0,                              // Unique identifier
         "title": "Slide Title",               // Slide heading
         "description": "Description text",    // Display text
         "imageId": 123,                       // WordPress attachment ID
         "imageUrl": "https://...",            // Full URL to image
         "buttonUrl": "https://example.com",   // CTA link (optional)
         "buttonText": "Click Here",           // Button label
         "buttonStyle": "primary",             // Style: primary|secondary|tertiary|ghost
         "buttonTarget": false                 // Open in new tab: true|false
       },
       // ... (up to 3 slides)
     ],
     "activeSlide": 0                          // Currently selected in editor
   }

   ATTRIBUTE VALIDATION:
   - Maximum 3 slides (enforced in JavaScript)
   - buttonText defaults to "Button content..."
   - imageId: 0 = no image
   - buttonUrl: empty string = no button
   - buttonStyle: must be one of 4 options
   - buttonTarget: boolean only

*/

   1. Visual feedback (blue border)

   3. onSelectImage() handler fires
   4. Image URL saved to attributes
   5. Preview appears in editor

/* ============================================
   6. FRONTEND CAROUSEL LOGIC
   ============================================

   INITIALIZATION (DOMContentLoaded):

   1. Query all .bnpp-carousel-wrapper elements
   2. For each carousel:
      a. Get container, slides, title items
      b. currentSlide = 0
      c. Call showSlide(0)
      d. Attach click handlers to titles
      e. Attach keyboard handlers

   SLIDE DISPLAY LOGIC:

   showSlide(n):
   1. Remove 'active' class from all slides
   2. Remove 'active' class from all titles
   3. Add 'active' class to slide[n]
   4. Add 'active' class to title[n]
   5. Update ARIA attributes
   6. currentSlide = n

   CSS CHANGES (automatic):
   - .diapositive.active { opacity: 1; z-index: 10; }
   - .diapositive { opacity: 0; z-index: 1; }
   - .bnpp-carousel-title-item.active { background: white; color: blue; }

   NAVIGATION:

   Title Click:
   1. Event listener fires
   2. goToSlide(index) called
   3. showSlide(index) executed
   4. Visual update

   Keyboard Navigation:
   ArrowLeft → prevSlide() → showSlide(currentSlide - 1)
   ArrowRight → nextSlide() → showSlide(currentSlide + 1)

   OPTIONAL AUTO-ROTATION:
   setInterval(() => nextSlide(), 10000);  // Every 10 seconds

*/

/* ============================================
   8. JAVASCRIPT API
   ============================================

   ACCESSING CAROUSEL INSTANCE:

   const wrapper = document.querySelector('.bnpp-carousel-wrapper');
   const carousel = wrapper.dataset.carouselInstance;

   Available Methods:
   - carousel.nextSlide()       // Show next slide
   - carousel.prevSlide()       // Show previous slide
   - carousel.goToSlide(index)  // Go to specific slide
   - carousel.currentSlide      // Current slide index (read-only)

   EXAMPLE USAGE:

   // Move to next slide
   carousel.nextSlide();

   // Go to specific slide
   carousel.goToSlide(1);  // Second slide

   // Get current slide
   console.log(carousel.currentSlide);  // 0, 1, or 2

   EVENT LISTENERS:

   // Add custom listener for slide change
   const wrapper = document.querySelector('.bnpp-carousel-wrapper');
   wrapper.addEventListener('slideChange', function(e) {
     console.log('Switched to slide:', e.detail.slideIndex);
   });

   PROGRAMMATIC CONTROL:

   // Auto-play carousel
   setInterval(() => {
     const wrapper = document.querySelector('.bnpp-carousel-wrapper');
     const carousel = wrapper.dataset.carouselInstance;
     carousel.nextSlide();
   }, 5000);

   // Keyboard shortcuts
   document.addEventListener('keydown', (e) => {
     const carousel = document.querySelector('.bnpp-carousel-wrapper').dataset.carouselInstance;
     if (e.key === 'n') carousel.nextSlide();
     if (e.key === 'p') carousel.prevSlide();
   });

*/

/* ============================================
   9. ACCESSIBILITY IMPLEMENTATION
   ============================================

   ARIA LABELS:

   Slides:
   - role="region"
   - aria-label="Slide 1: Slide Title"
   - aria-hidden="true" (inactive slides)

   Title Items:
   - role="tab"
   - aria-selected="true|false"
   - tabindex="0"

   Buttons:
   - Semantic <a> tag
   - Focus outline: 2px solid #0066cc

   KEYBOARD NAVIGATION:

   Tab:
   - Focus title items in order
   - Focus buttons
   - Standard focus management

   Arrow Keys (within region):
   - ArrowLeft → Previous slide
   - ArrowRight → Next slide

   Enter/Space:
   - Activate focused title item
   - Activate button

   SCREEN READER SUPPORT:

   On slide change:
   - aria-selected updated
   - aria-hidden updated
   - Screen readers announce new slide

   Button Text:
   - Uses visible text (not aria-label)
   - URL provided in href attribute

   Semantic HTML:
   - Uses <h3> for titles
   - Uses <p> for descriptions
   - Uses <a> for buttons

   FOCUS MANAGEMENT:

   - Focus trap not implemented (allow tab out)
   - Focus visible on all interactive elements
   - outline: 2px solid for focus indication
   - outline-offset: 2px for visibility

   TESTING:

   Screen readers:
   - Test with NVDA (Windows)
   - Test with JAWS (Windows)
   - Test with VoiceOver (Mac/iOS)
   - Test with TalkBack (Android)

   Keyboard only:
   - Tab through all elements
   - Use arrow keys on carousel
   - Verify focus order
   - Check focus visibility

*/

/* ============================================
   10. PERFORMANCE CONSIDERATIONS
   ============================================

   FILE SIZES:

   block.js: ~19 KB (minified)
   block.css: ~9 KB (minified)
   init.php: ~5 KB
   Total: ~33 KB

   OPTIMIZATION TIPS:

   1. Lazy Load Images:
      Add loading="lazy" to image tags

   2. Image Optimization:
      - Use optimized images (compressed)
      - Recommended: 1920x640px at 100-150 KB each
      - Use WEBP format if supported

   3. CSS Delivery:
      - Only loaded when block is present
      - wp_register_style with dependencies

   4. JavaScript Execution:
      - Deferred until DOM ready
      - No render-blocking scripts
      - Minimal DOM queries

   5. Animations:
      - CSS transitions (hardware accelerated)
      - opacity changes only (performance optimized)
      - 60fps animations

   MEMORY USAGE:

   Per carousel instance:
   - ~2 KB for configuration
   - Event listeners: ~500 bytes
   - DOM references: ~1 KB

   For 3 slides:
   - Minimal memory footprint
   - No memory leaks detected

   CACHING:

   - Leverage browser caching
   - CSS/JS files: 1 year expiration
   - Images: Use CDN or caching plugins

*/

/* ============================================
   11. COMMON CUSTOMIZATIONS
   ============================================

   ADDING A FOURTH SLIDE:

   1. In src/init.php, increase default slides:
      'default' => array( ... 4 items ... )

   2. In assets/block.js, remove this check:
      while (normalizedSlides.length < 3)

   3. Update CSS title item logic:
      width: (1920 - 286) / 4 = 433.5px

   CHANGING BUTTON COLORS:

   Primary (edit assets/block.css):
   .bnpp-button.primary {
     background-color: #YourColor;
     border-color: #YourColor;
   }

   ENABLE AUTO-ROTATION:

   In assets/block.js (around line 500):
   Uncomment:
   setInterval(() => {
     nextSlide();
   }, 10000);  // 10 seconds

   CHANGE AUTO-ROTATION SPEED:

   Replace 10000 with milliseconds:
   5000 = 5 seconds
   8000 = 8 seconds
   15000 = 15 seconds

   CUSTOM BUTTON TEXT WHEN EMPTY:

   In src/init.php, change:
   'buttonText' => 'Button content...',
   To:
   'buttonText' => 'Your Custom Text',

   DISABLE BUTTON TARGET OPTION:

   In assets/block.js, remove:
   ToggleControl for buttonTarget

   CHANGE SLIDE DIMENSIONS:

   1. In assets/block.css:
      .bnpp-carousel-container { height: 800px; }

   2. In assets/block.js:
      style: { height: '800px' }

   3. Update description position:
      .diapositive-description { top: 350px; }

   ADD SLIDE COUNTER:

   Create element:
   <div class="slide-counter">
     <span class="current">1</span> / <span class="total">3</span>
   </div>

   Update in showSlide():
   document.querySelector('.current').textContent = n + 1;

   IMPLEMENT MOUSE DRAG:

   Add touch/drag listeners:
   let startX, currentX;
   container.addEventListener('mousedown', e => startX = e.clientX);
   container.addEventListener('mousemove', e => currentX = e.clientX);
   container.addEventListener('mouseup', () => {
     if (startX - currentX > 50) nextSlide();
     if (currentX - startX > 50) prevSlide();
   });

*/

/* ============================================
   12. TROUBLESHOOTING GUIDE
   ============================================

   ISSUE: Block not appearing in editor

   Solution:
   1. Verify plugin is activated
   2. Check WordPress version (need 6.0+)
   3. Check browser console for JS errors
   4. Disable other plugins to check conflicts
   5. Clear browser cache

   ISSUE: Images not displaying

   Solution:
   1. Verify images uploaded to media library
   2. Check image URL in HTML source
   3. Verify permissions on uploads folder
   4. Check for CORS issues (external images)
   5. Ensure image paths are absolute URLs

   ISSUE: Buttons not showing

   Solution:
   1. Verify both URL and text are filled
   2. Ensure button text is not "Button content..."
   3. Check that 'display' CSS is set to 'inline-block'
   4. Verify CSS is loaded (check <head>)

   ISSUE: Carousel not responsive

   Solution:
   1. Check viewport meta tag in HTML
   2. Verify media queries in CSS
   3. Clear CSS cache
   4. Check for conflicting CSS
   5. Verify theme doesn't override styles

   ISSUE: Accessibility issues

   Solution:
   1. Test with screen reader:
      NVDA (free), JAWS (paid)
   2. Verify ARIA labels in HTML
   3. Check focus management
   4. Test keyboard navigation
   5. Validate HTML with W3C validator

   ISSUE: JavaScript console errors

   Solution:
   1. Check browser console (F12)
   2. Verify all dependencies loaded:
      wp-blocks, wp-element, wp-editor
   3. Check for jQuery conflicts (if using jQuery)
   4. Verify script enqueue order
   5. Check for syntax errors in custom code

   ISSUE: Performance problems

   Solution:
   1. Optimize images (use tinypng.com)
   2. Enable lazy loading
   3. Check for other slow plugins
   4. Verify no console errors
   5. Use browser DevTools Performance tab

   ISSUE: Mobile carousel broken

   Solution:
   1. Check viewport meta tag
   2. Verify mobile media queries
   3. Test on actual devices
   4. Clear mobile browser cache
   5. Check for touch event handlers

   DEBUG MODE:

   Enable WordPress debug in wp-config.php:
   define('WP_DEBUG', true);
   define('WP_DEBUG_LOG', true);

   Browser console (F12):
   console.log(attributes);
   console.log(slides);

*/
